# Orchestration

This repo uses [tx-ide](https://github.com/wiktordaniec/tx-ide-private) to coordinate Claude Code sessions in tmux.

Your first action: read `agents/COMMON.md` for the conventions every session in this system must follow.

If you are a worker session, your spawn prompt should have additionally directed you to a role file in `agents/`. If it didn't, ask the user which role you're meant to play.
